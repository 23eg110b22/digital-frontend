# DLO – Digital Life Organizer

## Setup

1. Install dependencies:
```
npm install
```

2. Start the app:
```
npm start
```

Opens at http://localhost:3000

## Features
- Login / Register / Forgot Password
- Bills Manager (add, pay, delete)
- Documents (upload, delete)
- Subscriptions (add, cancel)
- Pay Bills via GPay, PhonePe, Paytm
- Bank Payments (Card, Net Banking, Wallet)
- Analytics
- Settings with Dark Mode
- Toast notifications
- localStorage persistence
